プライバシーポリシー

対象アプリ：AI-YouTube-Studio
運営：フィクション現実課
最終更新：2026年11月14日

1．対象となる機能

本ポリシーは、運営者本人のMacで実行するAI-YouTube-StudioのYouTube連携機能を対象とします。運営者自身のYouTubeチャンネルへの非公開アップロード、確認が済んだ動画への予約公開の設定、およびその前後の確認に利用します。これらの処理は、運営者が設定した時刻に運営者のMac上で自動実行されることがあります。

2．アクセス・取り扱いを行う情報

  • 認証したYouTubeチャンネルの名前・IDなど、投稿先を確認するための情報
  • 重複確認、投稿状況確認、予約公開の可否の確認に用いる動画のID・タイトル・公開設定・予約公開日時・処理状況などの情報
  • 運営者がアップロード対象として指定した動画ファイル、タイトル、説明文などの投稿内容
  • Google OAuthの認可により発行されたアクセス用トークンと更新用トークン、アプリの接続用設定

3．利用目的

取得した情報は、投稿先チャンネルの確認、指定された動画のアップロード、同じ動画の重複投稿防止、処理状況の確認、処理と検査が完了した自分の動画への予約公開の設定、認証更新と中断した処理の再開に使用します。予約公開の許可は、アップロード済みの自分の動画の公開設定（公開日時）を変更する目的にのみ使用し、動画やコメントの削除、他のチャンネルの操作には使用しません。

Googleから取得した情報を、広告配信、販売、汎用AIモデルの学習のために使用しません。Google APIから受け取る情報の利用および他アプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

4．保存と管理

認証用ファイルは、運営者のMac内にあるアクセス権を制限した保存先で管理します。認証用トークンやクライアントシークレットを、画面、通常の実行ログ、公開用ファイルに表示しない設計です。

投稿記録、予約公開の記録、実行状態は、重複防止と再開のためにローカルに保存します。投稿する動画や説明文も、運営者が管理するローカルファイルを使用します。保存した情報は、運営者が不要になった時点で端末から削除できます。

5．送信先と第三者への提供

Google認証とYouTubeへの投稿・確認のため、必要な認証情報、動画、投稿内容をGoogleおよびYouTubeの公式サービスへ送信します。Googleから取得した情報を広告・販売の目的で第三者に提供しません。

アップロード後の動画と投稿内容は、YouTube上でも管理されます。予約公開を設定した動画は、予約日時にYouTubeによって公開されます。Google・YouTubeにおけるデータの取り扱いには、各サービスの規約とプライバシーポリシーが適用されます。

6．アクセス許可の取り消しと削除

Googleアカウントのアクセス許可設定から、本アプリへの許可を取り消せます。取り消し後は、再度認証するまでGoogle APIを利用できなくなります。設定済みの予約公開は取り消しによって解除されないため、公開を止める場合はYouTube Studioで予約を変更してください。

ローカルに保存した認証情報や投稿記録は、運営者が削除できます。アクセス許可を取り消したり、端末のファイルを削除したりしても、投稿済みの動画は自動的には削除されません。動画はYouTube Studioで管理・削除してください。

7．この説明サイトについて

このサイトには独自のアクセス解析や入力フォームを設けていません。GitHub Pagesで公開する場合、ホスティングを行うGitHubがセキュリティ目的で訪問者のIPアドレスを記録します。詳しくはGitHubのプライバシーに関する説明をご確認ください。

8．お問い合わせ・変更

お問い合わせは、Google認証の同意画面に表示されるユーザーサポートメールアドレスへお願いします。機能やデータの取り扱いを変更する場合は、本ページの内容と更新日も見直します。
